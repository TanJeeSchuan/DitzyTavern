# Reunify the two Chat Import projections

The developer import and the Staged Import both decoded the SillyTavern source once and then implemented adjacent author ownership, Message stamping, Control derivation, report/data assembly, and duplicate-warning composition separately — the developer path behind `resolveDeveloperAuthorGroups`, the staged path inside its commit machinery. We replaced that with one pure Import Projection (`src/server/sillytavern/import-projection.ts`): the adapter only decodes and validates, and the projection maps decoded source into native Conversation creation data under a resolution supplied by each path.

Both paths now supply one resolution data shape, `ImportProjectionResolution`, and never a custom implementation: the developer import uses the Default Import Policy (one Participant per trimmed author group, empty imported Definitions, deterministic Control), and the Staged Import supplies the user-confirmed Resolved Participant Plan. The projection owns Author Stamp placement, Control derivation (always deterministic from the resolved Participant count; resolutions carry no Control field), archive/report entries, and duplicate warning composition. Plan validation, Profile resolution, exact-duplicate confirmation gating, exact-artifact storage, and staging state stay with the paths that own them. The staged preview's initial groups now come from the same grouping primitive under the same trimmed rule, so the two paths can never drift; case and Unicode remain distinct, and the exact raw captured values stay untouched in preserved source data.

This refines the allocation in ADR-0025 without superseding it: the workflow boundary is unchanged, but duplicate-warning composition and author grouping are no longer per-importer concerns. It also unifies the blank-author placeholder on `UNKNOWN_IMPORTED_AUTHOR_NAME` ("Unknown imported author"), retiring the developer path's separate `"Blank Author"` constant. Staged-only concepts (suggestions, outcomes, staging tokens) never enter the projection.
